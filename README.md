# FreelanceHunt → Telegram

Общедоступный Telegram-бот: каждый пользователь пишет `/start` в личном чате и получает собственную подписку на проекты Freelancehunt. Добавлять Telegram ID новых пользователей на сервере не нужно.

## Личные настройки

Открой **⚙️ Настройки** или отправь `/settings`:

- **Имя и портфолио** — данные автора только для его откликов. Отправь `-`, чтобы очистить поле.
- **Добавить категорию по ID** — например, `99` (веб-программирование) или `180` (разработка ботов). До 30 категорий на пользователя; ненужные категории можно удалить, в том числе все.
- **Имена категорий** — собственные названия выбранных категорий.
- **Уведомления категорий** — отдельное включение/отключение каждой категории.
- **Мой промпт** — обычный текст с инструкциями для ИИ: опыт, стиль, язык и правила откликов. До 3500 символов Telegram.
- **Примеры откликов (JSON)** — личные примеры стиля: `{"examples": [{"input": {"project_title": "Пример"}, "output": "Текст отклика"}]}`. Цены и сроки программа рассчитывает отдельно.

Новый пользователь получает начальные категории из `SKILL_IDS`, нейтральный промпт, пустые примеры, имя и портфолио. Чужие настройки, история отправок, промпты и оценки ему не передаются. Старый фильтр Python/JavaScript/TypeScript применяется только к перенесённому профилю прежнего владельца; новым пользователям доступны любые выбранные категории.

После нового проекта бот автоматически присылает ответом черновик отклика, если ИИ включён. Под проектом доступна ручная генерация, под откликом — перегенерация. Бот не публикует ставки на Freelancehunt.

## Команды

- `/start` — открыть меню и возобновить уведомления.
- `/help` — показать меню и помощь.
- `/settings` — личные настройки.
- `/cancel` — отменить текущий ввод и вернуться в настройки.
- `/stop` — остановить свои уведомления, сохранив настройки. Возобновление через `/start`.

Бот работает в личных чатах. Кнопки из групп и чужих чатов не дают доступа к личным данным. Блокировка бота отключает рассылку этому пользователю и не мешает остальным.

## Запуск

1. Создай бота через [@BotFather](https://t.me/BotFather).
2. Получи токен [Freelancehunt API](https://freelancehunt.com/my/api).
3. Для генерации откликов укажи ключ Gemini.
4. Скопируй `.env.example` в `.env` и заполни секреты.
5. Запусти `docker compose up -d --build`.
6. Открой бота в Telegram и отправь `/start`.

Логи: `docker compose logs -f bot`.

## Настройки сервера

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | обязательна | Токен бота |
| `FREELANCEHUNT_TOKEN` | обязательна | Общий токен чтения проектов |
| `TELEGRAM_CHAT_ID` | пусто | Только ID прежнего владельца для однократного переноса данных |
| `SKILL_IDS` | `180` | Начальные категории новых пользователей |
| `POLL_INTERVAL` | `60` | Интервал опроса в секундах |
| `STATE_FILE` | `/data/state.json` | Старое состояние; личные данные создаются в соседней папке `users/` |
| `PROMPT_EXAMPLES_FILE` | рядом со `STATE_FILE` | Старые примеры для переноса владельцу |
| `QUOTE_FILE` | `/data/quotes.json` | Старые оценки для переноса владельцу |
| `SEND_EXISTING_ON_FIRST_RUN` | `false` | Присылать ли текущие проекты при первом опросе категории |
| `PAGE_SIZE` | `5` | Размер страницы истории |
| `HISTORY_SIZE` | `50` | Размер истории на категорию у каждого пользователя |
| `GEMINI_API_KEY` | пусто | Общий ключ ИИ; без него бот работает без генерации |
| `GEMINI_MODEL` | `gemini-3.1-pro-preview` | Модель ИИ |
| `GEMINI_ENABLED` | `true` | Общий переключатель ИИ |
| `GEMINI_TIMEOUT_SEC` | `20` | Таймаут запроса к ИИ |

Токены Freelancehunt и Gemini остаются серверными; запросы всех пользователей расходуют их общие квоты.

## Обновление существующего бота

Перед обновлением останови контейнер и сохрани копию `data/` и `.env`. Укажи прежний положительный `TELEGRAM_CHAT_ID`, затем пересобери и запусти контейнер. При первом запуске данные копируются в `data/users/<TELEGRAM_CHAT_ID>/`:

- `state.json` — категории, названия, отключённые уведомления, история и отметки отправки;
- `bids_examples.json` — личные примеры откликов;
- `system_prompt.md` — прежний промпт;
- `quotes.json` — зафиксированные оценки;
- `user.json` — сведения о регистрации и переносе.

В профиль владельца переносятся использовавшиеся ранее имя Никита и его портфолио. Их можно изменить в Telegram. Исходные файлы остаются на месте; повторный запуск не перезаписывает личные настройки. Для отката останови новый контейнер, восстанови прежние код/образ и резервную копию `data/`.

Оценки стоимости независимы по пользователям и сохраняются при перегенерации текста. Существующая формула: 12 USD/час, категории объёма 4/8/16/24/40/80 часов, округление и бюджет как нижняя граница. Для неопределённого ТЗ цена и срок не выводятся.

## Устройство и проверка

`UserRegistry` хранит отдельные папки по Telegram ID. Middleware определяет пользователя по отправителю личного сообщения, передаёт обработчику его хранилище и копию настроек. `PublicNotifier` запрашивает объединение категорий один раз за цикл и отдельно применяет подписки, названия, историю и ИИ каждого получателя. Успешный пустой ответ API тоже инициализирует категорию, чтобы следующий первый проект не потерялся.

```sh
pip install -r requirements.txt
python -X utf8 -m unittest discover -s tests
```

Тесты проверяют перенос старых данных, сохранение после перезапуска, изоляцию пользователей и промптов, доступ к настройкам, независимую рассылку, блокировку получателя и расчёт стоимости.
